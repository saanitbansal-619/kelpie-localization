## Commands to rerun

From the repository root:

```powershell
powershell -ExecutionPolicy Bypass -File arduino_pinger\run_host_verification.ps1
```

Host tests only, if `g++` is on PATH:

```powershell
g++ -std=c++11 -Wall -Wextra -I arduino_pinger -o $env:TEMP\test_pinger_logic.exe arduino_pinger\test_pinger_logic.cpp
& $env:TEMP\test_pinger_logic.exe arduino_pinger\HOST_VERIFICATION.md
```

Firmware build, if `arduino-cli` is on PATH:

```powershell
arduino-cli compile --warnings all --fqbn arduino:avr:uno arduino_pinger/robosub_pinger
```

If the CLI is missing, install [Arduino IDE 2](https://www.arduino.cc/en/software) or the standalone Arduino CLI, then:

```powershell
arduino-cli core update-index
arduino-cli core install arduino:avr
arduino-cli compile --warnings all --fqbn arduino:avr:uno arduino_pinger/robosub_pinger
```

Arduino IDE 2 also ships a CLI that is often not on PATH:

`%LOCALAPPDATA%\Programs\Arduino IDE\resources\app\lib\backend\resources\arduino-cli.exe`
